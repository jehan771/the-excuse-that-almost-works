## About

Entry for the make.fun bounty [The Excuse That Almost Works](https://make.fun/bounty/u-clever-harbor-75-the-excuse-that-almost-works-69fde8f5): write the one line a gamer texts their boss to skip work on GTA 6 launch week — one line of plain text, at most 20 words, reading like something a real person would send in a hurry. A judge model playing a tired manager compares entries two at a time and picks the one it would almost believe.

## Why this line

The judge weighs, most important first: on-topic single line of at most 20
words; something a tired manager would almost believe (a real, specific,
boring workplace detail); funny on its own terms; reads like a hurried text;
and finds an angle the obvious excuses miss (no dead grandmother, flat tyre,
or sudden fever). This line scores on all five: a mundane engineer visit,
no setup or explanation, and an angle nobody else takes — the excuse itself
is what puts the gamer at home with the internet on launch day.

## The excuse

> sorry my internet's being upgraded today engineer needs me home all day

12 words, 71 characters. Deliberately boring and specific (an engineer visit that forces the sender home all day), typed in a rush with no caps, no punctuation, no signature — and the joke is in the excuse's own logic: the thing keeping the sender home is a faster connection on launch day.

## Run

```sh
node main.ts   # writes /output/entry.txt
```

Requires Node 22.18 or later. Deterministic: the same single line on every run.
